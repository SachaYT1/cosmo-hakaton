# AF: обучение и проверка на CPU

Модуль принимает VIIRS I1–I5, углы, маску валидности и AUX и возвращает бинарную
маску природного горения 256×256. Для обучения и инференса GPU не требуется.

## Запуск

Команды выполняются из `cosmo-hakaton/models`, Python 3.12.

```bash
python -m pip install -r requirements-af.txt
python -m scripts.train_af --data-dir ../../../../train --threads 6
python inference.py --data-dir /path/to/test --output outputs/submission.csv
python -m scripts.validate_submission outputs/submission.csv --data-dir /path/to/test
python -m unittest discover -s tests -v
```

`inference.py` читает все строки `sample_submission.csv`. AF использует веса из
`configs/af.json`; для BS по умолчанию включены уже обученные правила. BS U-Net
можно включить через `--bs-model unet`, когда появятся её конфигурация и веса.

Активная модель использует LightGBM, 100 контекстных признаков и порог
0.44. На трёх фолдах по датам 2019–2023 получено `F1_af=0.953463` после
подбора порога по OOF; 2024 год не участвовал в выборе. Это оценка на
обучающей части, а не результат скрытого теста. В репозитории оставлены только
рабочие runtime-файлы: `configs/af.json` и
`weights/af_augmented_best_lgb.txt`. Метрики предыдущего бейзлайна
`F1_af=0.952759` сохранены в `reports/af_baseline.json`, но его веса удалены после
финального сравнения.

Повторное обучение сохраняет веса в `weights/`, рабочий порог и состав моделей в
`configs/af_candidate.json`, OOF в `cache/af_candidate_oof.npz`, метрики
в `reports/af_candidate_training.json`. Выбранная конфигурация `af.json`
не перезаписывается. Настройки обучения заданы отдельно
в `configs/af_train.json`. `--threads 6` ограничивает CPU-параллелизм; модели
обучаются последовательно. Кэш и датасеты не включаются в Git.

## Метрика и проверка

По стр. 13 постановки сначала суммируются TP, FP и FN по всем пикселям всех
оцениваемых чипов, затем вычисляется `F1_af = 2TP / (2TP + FP + FN)`.
При нулевом знаменателе результат равен 1. F1 по чипам не усредняется.
Невалидные/облачные пиксели не исключаются из оценки. Отброшенные предварительным
фильтром положительные пиксели добавляются в FN; отброшенный фон — TN, который
не входит в формулу F1.

Стандартное повторное обучение использует пять фолдов: все чипы одной даты
находятся в одном фолде. Активная модель выбиралась на трёх фолдах
2019–2023 годов; протокол записан в `reports/af_augmented_best.json`.
Порог выбирается по объединённым out-of-fold предсказаниям на сетке 0.05–0.95
с шагом 0.01. Бинаризация в обучении, инференсе и визуализации одинакова: `p >= t`.
OOF F1 с выбранным на тех же данных порогом — оценка с подбором порога, а не
независимая оценка качества. Дополнительно сохраняется F1 при фиксированном 0.5.

Для временной проверки, где порог не подбирается на проверочном году:

```bash
python -m scripts.train_af --data-dir ../../../../train --threads 6 \
  --validate-year 2024 --validation-folds 3
```

Сначала на 2019–2023 годах строятся три фолда по датам и подбирается порог.
Затем модель обучается на всех этих ранних годах и проверяется на 2024 году.
После проверки отдельно обучается финальная модель на всех обучающих годах.
Временное разделение допускает повторение территорий между годами; оно не
полностью воспроизводит разделение private test одновременно по месту и времени.

Это только AF-компонента. Полная метрика соревнования равна
`0.35*F1_af + 0.35*IoU_burn + 0.30*mIoU_sev` и требует предсказаний BS.

## Признаки и ограничения постановки

Сохраняется предварительный отбор по I4 и превышению температуры над фоном.
Исходные 31 признак дополнены до 100: фон в кольцах 7/15/31 с исключённым
центром 3×3, разброс температуры, отклонения от локальных медиан, доля горячих
соседей, локальный тип покрова, различия отражения в SWIR и температурные
контрасты с AUX. Каналы отражения, отсутствующие ночью, остаются NaN и
обрабатываются деревьями как пропуски.

Признаки вычисляются только из растров текущего чипа. В модель не передаются
`chip_id`, координаты, дата, спутник, `n_fire_px` или эталонная маска. Дата
используется только для разбиения обучающих данных. Тестовые территории и даты
не восстанавливаются. Исторические внешние данные подключаются только при
явном запуске дополнительного обучения.

Тип покрова не служит жёстким запретом: даже среди размеченных природных очагов
есть пиксели с кодами застройки и воды. Постоянный газовый факел невозможно
надёжно отличить от природного горения по одному кадру во всех случаях.
Указанная в постановке история зимних срабатываний в этом модуле недоступна;
полное решение этой проблемы не заявляется.

## Повторение экспериментов

Список проверенных конфигураций находится в `configs/af_search.json`, результаты
— в `reports/af_experiments.json`. Эксперименты используют только годы до
отложенного последнего года. LightGBM 4.6.0 включён в `requirements-af.txt`.

```bash
python -m scripts.benchmark_af --data-dir ../../../../train --seconds 1800
# Повторить один вариант:
python -m scripts.benchmark_af --data-dir ../../../../train --trial baseline --seconds 300
```

Ограничение времени принудительно останавливает процесс, включая нативное
обучение. Завершённые варианты сохраняются и пропускаются при повторном запуске.
Кэш признаков проверяется по исходному коду, метаданным и файлам данных.

## Открытые внешние данные

В `data/external/usfs_viirs_conus/` скачаны официальные архивы USFS за
2017 и 2018 годы: 770 669 термоточек по CONUS. Команда
`python -m scripts.download_af_open_data` воспроизводимо скачивает разрешённые
открытые архивы USFS и комплект NOAA без учётной записи. Затем
`python -m scripts.prepare_af_points` проверяет годы и координаты, создаёт
`detections.csv.gz` и `manifest.json` с URL и SHA-256 исходных архивов.
Термоточки не являются меткой «природный пожар»: они служат индексом для
поиска снимков и анализа повторяемости промышленных источников. Сами точки
не подаются в обучение пиксельной модели.

В `data/external/noaa_viirs/2022-12-15/t0429233/` скачаны пять исходных
VIIRS I1–I5 SDR, геопривязка и NOAA AF I-band EDR. Гранула целиком лежит
над Австралией, а дата вне периода апрель–октябрь 2019–2025 из постановки.
`python -m scripts.prepare_af_noaa` проверяет SHA-256 файлов, дату и границы
каждого чипа и создаёт 14 чипов формата AF в `data/external/noaa_af_chips/`.
Значение маски 255 означает отсутствие надёжной метки; класс 1 означает
детекцию NOAA с номинальной/высокой уверенностью, кроме помеченных
постоянных аномалий; чистая суша и указанные промышленные категории получают
класс 0. Это **слабая разметка**, не эталон природных пожаров. Каналы AUX,
DEM заполняется из канала `Height` геопривязки GITCO. Landcover и погодные
каналы, которых нет в комплекте NOAA, остаются NaN и обрабатываются моделью
как пропуски. По умолчанию внешние чипы не участвуют в обучении и оценке.

Для обучения с внешними чипами:

```bash
python -m scripts.train_af --data-dir ../../../../train --threads 4 --folds 3 \
  --external-dir data/external/noaa_af_chips --external-weight 0.02
```

Внешние примеры входят только в обучение каждого фолда и имеют вес 0.02;
проверочные фолды содержат только чипы организаторов. Промежуточные результаты
сохраняются в `cache/af_augmented_oof.npz`. После проверки тем же OOF-протоколом
лучший вариант перенесён в `configs/af.json`, а проигравшие runtime-веса и
конфигурации удалены. Участки и даты из тестового сезона и региона не
используются; координаты и даты внешних примеров не подаются модели.

Полная подготовка и аудит выполняются одной командой из `models/`:

```bash
python -m scripts.prepare_af_external --download
```

Если исходные файлы уже скачаны, флаг `--download` можно убрать. Итоговый
машиночитаемый отчёт создаётся в `reports/af_external_data.json`.

Для расширения набора скрипт сначала просматривает компактные маски AF EDR и
только затем скачивает тяжёлые I1–I5 и GEO для наиболее полезных гранул:

```bash
python -m scripts.discover_af_noaa --max-granules 24 --max-gb 8
python -m scripts.prepare_af_external
```

По умолчанию проверяются выбранные даты с декабря 2022 по февраль 2023 года.
Каждая дата проходит тот же запрет апреля–октября, а каждый готовый чип должен
целиком попасть в один из удалённых разрешённых регионов. Ограничения объёма,
число гранул, минимальное число детекций и шаг просмотра задаются аргументами.
